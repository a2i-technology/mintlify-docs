How-to documentation for Allied staff: practical walkthroughs, onboarding materials, and reference guides.

## Guides vs procedures

- **Guides** — General how-to documentation (e.g. "How to use Linear", "Getting started with Git"). Useful for onboarding and day-to-day reference.
- **Procedures** — Policy-linked execution steps. Created only when a policy requires them and there is recurring friction or risk. More formal and auditable.

Guides are lightweight; procedures are tied to policy and compliance.
