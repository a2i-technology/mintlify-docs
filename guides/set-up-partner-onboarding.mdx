End-to-end checklist when bringing a **partner** (not only a codename) into collaboration. Programme-only codenames stay in the [Codenaming](../operations/portfolio/codenaming) registry without this full flow.

## Checklist

1. **Codename** — Row added to the [Codenaming](../operations/portfolio/codenaming) registry (partner type); name not already in use.
2. **Google Workspace** — If isolated Workspace is required: [Set-up: Partner sub-domain](./set-up-partner-subdomain) (sub-domain, accounts, Shared Drive).
3. **Matrix** (when live) — Partner host `<code_name>.a2i.network`, accounts, collaboration room (e.g. `#falcon:a2i.network`); invite Allied liaisons.
4. **Welcome pack** — Send Workspace links, Matrix guidelines if used, and support contacts.
