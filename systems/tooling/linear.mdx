Linear is the **execution system of record** for tasks, tickets, and day-to-day operational work.

## What lives in Linear

- Tasks and tickets
- Work execution
- Sprint-like cadence (if used)
- Day-to-day operational work

## What does not live in Linear

- Definitive strategy or policy (→ Git)
- Organisational definitions (→ Git)

## Linking pattern

- Each project in Git (operations/active/project-x) includes a link to Linear project and Drive folder
- Linear project description links back to Git project README and Drive folder
- No mirroring of issues in Git
